# Vanidiosas - Premium Women's E-commerce

A modern, high-performance e-commerce platform designed for **Vanidiosas**, a premium women's footwear brand. This project focuses on delivering an exceptional user experience, high conversion rates, and a sleek, fashion-forward interface inspired by top industry standards.

## 🚀 Tech Stack & Architecture

This project is built using a modern, scalable tech stack focused on performance and type safety:

*   **Astro:** Utilized as the core framework for its ultra-fast server-side rendering (SSR) and partial hydration (Islands Architecture), ensuring optimal SEO and fast loading speeds.
*   **React:** Powers the dynamic and interactive client-side features, such as the shopping cart, product filtering, and checkout flow.
*   **Tailwind CSS (v4):** Used for utility-first responsive design, ensuring a premium, consistent visual identity across all devices.
*   **TypeScript:** Implemented under a strict configuration to ensure code reliability, maintainability, and self-documenting logic.

*   **Phase 2:** Dynamic Product Catalog & State Management (React Cart).
*   **Phase 3:** Backend Integration & Database Architecture (Product Inventory & Orders).
